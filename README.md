# VibeDistill

把播客、视频和深度长文，脱水成一句值得记住的话。一个面向长内容整理与个人知识归档的交互式前端作品。

[在线体验](https://dryout-idea-slicer.apps.workbuddy.host/?sharecode=3SJVVFVOPZ)

## 核心亮点

- **内容脱水**：输入标题、来源与逐字稿，在本地完成句子提取、金句筛选、核心结论和结构化要点生成。
- **思想画廊**：以高光金句为视觉主体，支持关键词、来源、标签和星标筛选，归档内容持久保存在浏览器中。
- **阅读与批注**：三段式结构化论据配合可编辑个人批注，形成完整的阅读与复盘闭环。
- **藏书票导出**：提供三套平面构成配色，可一键生成并下载 1080 × 1440 高清金句卡片。
- **三套视觉主题**：原色构成、蓝图纸版与夜间展厅，均采用平涂色块、粗线框和硬边投影。
- **完整响应式体验**：针对桌面、平板和手机重新编排信息层级，并支持键盘操作与减少动态效果偏好。

## 技术栈

- React 19
- Vite 8
- 原生 CSS Design Tokens
- Lucide React
- Canvas 2D（高清卡片导出）
- localStorage（本地持久化）

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建
npm run build

# 预览生产构建
npm run preview
```

默认访问地址：`http://localhost:5173`

## 项目结构

```text
.
├── src/
│   ├── components/        # 控制台、画廊、详情抽屉与藏书票
│   ├── data/              # 初始归档数据
│   ├── lib/               # 内容提炼与图片导出
│   ├── App.jsx            # 应用状态与页面编排
│   └── index.css          # 设计令牌、布局与三套主题

├── index.html
└── vite.config.js
```

## 数据说明

本项目为纯前端实现，不依赖后端服务。归档、批注、主题和演示账户状态仅保存在当前浏览器的 `localStorage` 中，不会上传到服务器。
